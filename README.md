# ระบบเว็บไซต์ร้านอลูมิเนียมลายไม้ (Flask single-file)

เว็บไซต์สำหรับธุรกิจขาย **ประตู หน้าต่าง ระแนงปรับองศาได้ มุ้งลวด มุ้งจีบ มุ้งนิรภัย** อลูมิเนียมลายไม้
ลูกค้าคำนวณราคาเองได้ตามขนาดจริง (กว้าง × สูง) และปรับรูปแบบได้ ส่วนหลังบ้านคำนวณวัสดุ ต้นทุน และกำไรให้อัตโนมัติจากสูตรวัสดุ (BOM)

- โค้ดทั้งหมดอยู่ในไฟล์เดียว: `app.py`
- หน้าตาใช้ Tailwind CSS ผ่าน CDN (ไม่ต้อง build)
- ฐานข้อมูล SQLite (`alu_shop.db`) สร้างเองพร้อมข้อมูลตัวอย่างตอนรันครั้งแรก

---

## 1. การติดตั้งและรัน

ต้องมี Python 3.9 ขึ้นไป

```bash
pip install flask
python app.py
```

| หน้า | URL |
|---|---|
| หน้าร้าน | http://127.0.0.1:5000 |
| หลังบ้าน | http://127.0.0.1:5000/admin |

บัญชีผู้ดูแลเริ่มต้น: **admin / admin1234** (ควรเปลี่ยนก่อนใช้งานจริง ดูหัวข้อ 5)

> ถ้าเครื่องต่อเน็ตไม่ได้ หน้าเว็บจะไม่มีสไตล์ เพราะ Tailwind และฟอนต์ Prompt โหลดจาก CDN

## 2. หน้าร้าน (สำหรับลูกค้า)

### หน้าแรก `/`
แสดงสินค้าแยกตามหมวด พร้อมภาพตัวอย่างและ "ราคาเริ่มต้น" คลิกสินค้าเพื่อไปหน้าคำนวณราคา

### คำนวณราคา `/calculator`
1. **เลือกสินค้า** — ประตู / หน้าต่าง / ระแนง / มุ้งกันยุง / มุ้งนิรภัย
2. **ใส่ขนาด** กว้าง × สูง (ซม.) พิมพ์หรือเลื่อนแถบได้ ระบบจำกัดช่วงขนาดตามสินค้า
3. **ปรับรูปแบบ** (แสดงเฉพาะตัวเลือกที่สินค้านั้นมี)
   - จำนวนบาน
   - ลูกฟักแนวนอน 0–3 เส้น (ประตู/หน้าต่าง)
   - ทิศทางการเปิด / ฝั่งเก็บมุ้ง (บานเปิด 1 บาน, มุ้งจีบ 1 บาน)
   - องศาใบระแนง 0–90° (ระแนง — ใช้แสดงภาพตัวอย่าง)
4. **เลือกสีลายไม้** และ **ชนิดกระจก** (สินค้าที่มีกระจก)
5. ใส่จำนวนชุด → ราคาขึ้นทันที → กด **เพิ่มลงตะกร้า**

ภาพตัวอย่างด้านขวาเปลี่ยนตามขนาด จำนวนบาน สี และไส้บานแบบเรียลไทม์

### ตะกร้า `/cart`
- ปรับจำนวน, ลบรายการ, หรือกด **✎ แก้ไขรูปแบบ/ขนาด** เพื่อกลับไปแก้ในหน้าคำนวณ แล้วกด "บันทึกการแก้ไข"
- ตะกร้าเก็บในเบราว์เซอร์ของลูกค้า (localStorage) และคำนวณราคาใหม่ทุกครั้งที่เปิดหน้า
- กรอกชื่อ เบอร์โทร (จำเป็น) ที่อยู่หน้างาน หมายเหตุ → **ส่งคำสั่งซื้อ**
- ได้ **เลขที่คำสั่งซื้อ** (เช่น `AL261029AB12`) พิมพ์ / บันทึก PDF ได้

### ติดตามงาน `/track`
ใส่เลขที่คำสั่งซื้อ + เบอร์โทรที่ใช้สั่ง เพื่อดูสถานะ:
ใหม่ → ยืนยัน/นัดวัดหน้างาน → กำลังผลิต → พร้อมติดตั้ง → ติดตั้งเสร็จสิ้น

> ลูกค้าเห็นเฉพาะราคาขาย ข้อมูลต้นทุนไม่ถูกส่งออกไปที่หน้าร้าน และเซิร์ฟเวอร์คำนวณราคาใหม่ทุกครั้งที่สั่ง (แก้ราคาจากฝั่งเบราว์เซอร์ไม่ได้)

## 3. หลังบ้าน (สำหรับเจ้าของร้าน) `/admin`

| เมนู | ใช้ทำอะไร |
|---|---|
| **แดชบอร์ด** | ยอดขาย ต้นทุน กำไรขั้นต้น (ไม่รวมงานยกเลิก), จำนวนงานแต่ละสถานะ, สินค้าขายดี |
| **คำสั่งซื้อ** | ค้นหา/กรองตามสถานะ, เปิดดูใบสรุปต้นทุน/ใบสั่งผลิต, เปลี่ยนสถานะ, บันทึกภายใน, ลบ, พิมพ์ |
| **สินค้า & สูตร BOM** | ตั้งค่าสินค้า, สูตรวัสดุ, % กำไร, ราคาขั้นต่ำ, ช่วงขนาด, เปิด/ปิดการขาย, ทดลองคำนวณ |
| **ราคาวัสดุ** | แก้ราคาต้นทุนวัสดุ เพิ่ม/ลบวัสดุ |
| **สี / กระจก** | จัดการสีลายไม้ (% ส่วนเพิ่ม) และชนิดกระจก (ราคา/ตร.ม.) |
| **ตั้งค่า** | ชื่อร้าน เบอร์โทร LINE ที่อยู่, % เผื่อเศษวัสดุ, การปัดราคา |

### ใบสรุปต้นทุน / ใบสั่งผลิต (ในหน้าคำสั่งซื้อ)
แต่ละรายการแสดงวัสดุทุกตัว สูตร ปริมาณต่อชุด ปริมาณรวม ราคาต่อหน่วย และต้นทุน
ด้านล่างมี **สรุปวัสดุที่ต้องเบิก/สั่งซื้อ** รวมทั้งคำสั่งซื้อ

> คำสั่งซื้อเก็บราคาและต้นทุน ณ วันที่สั่ง ถ้าแก้ราคาวัสดุภายหลัง คำสั่งซื้อเก่าจะไม่เปลี่ยน

## 4. ระบบคำนวณราคา

### ขั้นตอนการคิด (ต่อ 1 ชุด)

```
ค่าวัสดุ     = Σ (ปริมาณจากสูตร × ราคาวัสดุ)      ← อลูมิเนียมบวก % ส่วนเพิ่มตามสีที่เลือก
             + ค่ากระจก (A × 0.9 × ราคากระจก/ตร.ม.)  ← เฉพาะสินค้าที่ใช้กระจก
เผื่อเศษ     = (อลูมิเนียม + มุ้ง + กระจก) × % เผื่อเศษ
ค่าแรง       = รายการวัสดุหมวด "ค่าแรง"
ต้นทุนรวม    = ค่าวัสดุ + เผื่อเศษ + ค่าแรง
ราคาขาย      = max(ต้นทุนรวม × (1 + % กำไร), ราคาขั้นต่ำ)  แล้วปัดขึ้นตามค่า "ปัดราคา"
ราคารวม      = ราคาขาย × จำนวนชุด
```

### ตัวแปรที่ใช้ในสูตร BOM

| ตัวแปร | ความหมาย |
|---|---|
| `W` | ความกว้าง (เมตร) |
| `H` | ความสูง (เมตร) |
| `A` | พื้นที่ W × H (ตร.ม.) |
| `L` | เส้นรอบรูป 2 × (W + H) (เมตร) |
| `P` | จำนวนบาน |
| `D` | จำนวนลูกฟักแนวนอนต่อบาน |

ฟังก์ชันที่ใช้ได้: `ceil` `floor` `min` `max` `round` `abs` `sqrt` และ `+ - * / // % **`

### ตัวอย่างสูตร

| วัสดุ | สูตร | ความหมาย |
|---|---|---|
| วงกบ | `L` | ยาวเท่าเส้นรอบรูป |
| กรอบบาน + ลูกฟัก | `P*2*(W/P+H) + D*W` | เส้นรอบรูปของทุกบาน + เส้นลูกฟัก |
| รางบน-ล่าง | `2*W` | |
| ลูกล้อ | `P*2` | 2 ลูกต่อบาน |
| ใบระแนง | `ceil(H/0.1)*W` | ใบทุก 10 ซม. ยาวเท่าความกว้าง |
| มุ้ง | `A*1.1` | เผื่อขอบ 10% |
| ค่าแรง | `max(A,1.5)` | คิดขั้นต่ำ 1.5 ตร.ม. |

ระบบตรวจสูตรตอนบันทึก ถ้าสูตรผิดหรือใช้คำสั่งที่ไม่อนุญาตจะบันทึกไม่ได้ (ไม่ได้ใช้ `eval` ของ Python จึงปลอดภัย)

### ขั้นตอนแนะนำก่อนเปิดใช้งานจริง
1. **ราคาวัสดุ** — แก้ราคาตัวอย่างทั้งหมดเป็นราคาต้นทุนจริงของร้าน
2. **สี / กระจก** — ปรับรายการสีและราคากระจกให้ตรงกับที่ร้านมี
3. **ตั้งค่า** — ใส่ชื่อร้าน เบอร์โทร LINE ที่อยู่ และ % เผื่อเศษ
4. **สินค้า** — เปิดสินค้าแต่ละตัว ตรวจสูตร BOM, % กำไร, ราคาขั้นต่ำ แล้วใช้กล่อง **ทดลองคำนวณต้นทุน** ด้านขวาเทียบกับราคาที่ร้านเคยขายจริง

### เพิ่มสินค้าใหม่
1. หน้า **สินค้า & สูตร BOM** → กรอก slug (a-z, 0-9, -) ชื่อ และหมวด → สร้าง
2. ในหน้าแก้ไข เลือก **ภาพตัวอย่าง** (บานเลื่อน / บานเปิด / ระแนง / มุ้งจีบ) และ **ไส้บาน**
3. ใส่จำนวนบานที่เลือกได้ เช่น `1,2` ติ๊ก "ใช้กระจก" / "มีลูกฟัก" ถ้ามี
4. เพิ่มวัสดุในตาราง BOM (มีช่องว่างให้เพิ่มครั้งละ 5 แถว กดบันทึกแล้วจะได้แถวว่างใหม่)
5. ทดลองคำนวณ แล้วติ๊ก **เปิดขาย** → บันทึก

## 5. ตั้งค่าผ่าน Environment Variables

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `ADMIN_USER` | `admin` | ชื่อผู้ใช้หลังบ้าน |
| `ADMIN_PASSWORD` | `admin1234` | รหัสผ่านหลังบ้าน |
| `SECRET_KEY` | สุ่มใหม่ทุกครั้งที่รัน | กุญแจเข้ารหัส session — **ควรตั้งค่า** ไม่งั้นทุกคนจะหลุดล็อกอินเมื่อรีสตาร์ต |
| `DB_PATH` | `alu_shop.db` ข้างไฟล์ `app.py` | ตำแหน่งไฟล์ฐานข้อมูล |
| `PORT` | `5000` | พอร์ต |
| `FLASK_DEBUG` | `1` | ตั้ง `0` เพื่อปิดโหมด debug |

ตัวอย่าง (PowerShell):

```powershell
$env:ADMIN_PASSWORD = "รหัสที่ยากเดา"
$env:SECRET_KEY = "ข้อความสุ่มยาวๆ"
$env:FLASK_DEBUG = "0"
python app.py
```

ตัวอย่าง (Linux / macOS):

```bash
ADMIN_PASSWORD='รหัสที่ยากเดา' SECRET_KEY='ข้อความสุ่มยาวๆ' FLASK_DEBUG=0 python app.py
```

## 6. ขึ้นใช้งานจริง (Production)

`python app.py` เหมาะสำหรับทดสอบเท่านั้น สำหรับใช้งานจริงให้รันผ่าน WSGI server เช่น

```bash
pip install waitress
waitress-serve --port=8000 app:app
```

(Linux ใช้ `gunicorn -w 2 -b 0.0.0.0:8000 app:app` ได้) แล้ววาง Nginx / Caddy ไว้ด้านหน้าพร้อม HTTPS
อย่าลืมตั้ง `ADMIN_PASSWORD`, `SECRET_KEY` และ `FLASK_DEBUG=0`

## 7. สำรองและรีเซ็ตข้อมูล

- **สำรองข้อมูล:** คัดลอกไฟล์ `alu_shop.db` เก็บไว้ (ข้อมูลทั้งหมดอยู่ในไฟล์นี้)
- **รีเซ็ตเป็นข้อมูลตัวอย่าง:** หยุดโปรแกรม ลบ `alu_shop.db` แล้วรันใหม่ (คำสั่งซื้อทั้งหมดจะหายด้วย)
- ข้อมูลตัวอย่าง (วัสดุ สินค้า สี กระจก) จะถูกใส่เฉพาะตอนตารางนั้นยังว่างเท่านั้น จึงไม่ทับข้อมูลที่แก้ไว้

## 8. โครงสร้างข้อมูล (SQLite)

| ตาราง | เก็บอะไร |
|---|---|
| `settings` | ข้อมูลร้าน, % เผื่อเศษ, การปัดราคา |
| `materials` | วัสดุ: รหัส ชื่อ หน่วย ราคาต้นทุน หมวด |
| `products` | สินค้า: แบบภาพ ไส้บาน จำนวนบาน ช่วงขนาด % กำไร ราคาขั้นต่ำ |
| `bom` | สูตรวัสดุของแต่ละสินค้า |
| `finishes` | สี/ลายไม้ และ % ส่วนเพิ่ม |
| `glass_types` | ชนิดกระจกและราคา/ตร.ม. |
| `orders` | คำสั่งซื้อ ข้อมูลลูกค้า รายการ (JSON พร้อม BOM ณ วันที่สั่ง) ราคา ต้นทุน สถานะ |
